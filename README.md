# 💬 Groq ChatBot Using LLM
A Streamlit-powered document QA assistant using Groq LPUs, LangChain, and FAISS.

## Features
- Upload PDF documents and split them into semantic chunks.
- FAISS vector store with local MiniLM embeddings.
- High-speed question answering using Groq's Llama models.
